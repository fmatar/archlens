## 🤝 How to Become a Contributor

We welcome contributions across polyglot language scanners, MCP server capabilities, canvas visualization ergonomics, and documentation!

1. Read the **[Contributing Guidelines](CONTRIBUTING.md)** and **[Code of Conduct](CODE_OF_CONDUCT.md)**.
2. Explore the **[Developer & Contributor Guide](docs/guide/DEVELOPER_GUIDE.md)** for step-by-step instructions on local development, adding new language scanners, and extending the MCP server.
3. Check open issues or the **[Product Roadmap](ROADMAP.md)** and open a Pull Request targeting `develop`.
